# reverb-sisters and echo-brothers, rejoice!

this will not work if you have other mods that affect regular_weapon_sfx as that soundbank is necessary for the volume increase for the 'fake echo' of the guns that sbz deliberately lowered for whatever reason

this also may not work if you have autofire sound fix installed, as that mod removes the fps echo entirely somehow

if you do not like the custom echo then you can delete the 'streamed' folder, that way you will restore the vanilla echo but with custom loudness

i recommend using 2013-styled if you are going to play a lot because heat-like can be headache inducing with how loud and intense it can get, im keeping it up if anyone wants to make cinematics about payday etc.

useless fun fact:

the streamed sounds are pre-made fake echo because the engine has been completely butchered to NOT process it live at all anymore

they used to be very short but loud noises for the engine to process unlike whatever we have today

init.bnk is responsible for configuring reverb settings for acoustic presets but currently it is impossible to alter at all
